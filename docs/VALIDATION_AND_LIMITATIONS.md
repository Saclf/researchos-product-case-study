文档检查不等于应用测试。这里不提供测试通过率、覆盖率、响应时间、模型成功率或新增用户验收结论。

## 稳定版的主要限制

| 限制 | 对用户和展示陈述的影响 |
|---|---|
| 分析与摘要入口最多传入前 30,000 个字符 | 不能宣称长论文全文分析；也不能把字符范围等同于模型理解范围 |
| 分析 / 摘要仍可能阻塞界面 | 不宣称稳定版已具备后续后台执行改进 |
| 内部链接首次点击可能延迟 | 不承诺所有定位操作始终即时响应 |
| 从选区加入术语本不会自动生成中文解释 | 不把术语录入描述为自动完成解释 |
| 术语与关联文献双向检索仍有缺口 | 不宣称已有完整知识关联能力 |
| 完整科研笔记系统仍在设计阶段 | 不将长期知识系统愿景描述为完整交付 |
| OCR 不应作为本版已完成能力宣传 | 不用扫描文献示例暗示已经过 OCR 验证 |
| 模型输出需人工核对 | 不保证事实准确、引文支持或科研正确性 |
| 缺乏普遍兼容性与效果数据 | 不宣传所有模型通用、用户规模或效率提升百分比 |

## 后续开发和真实模型边界

后台分析、结果归属校验、完整性门禁、分块证据、独立 Quick/Deep 和全文阅读 MVP 均不属于本文所述稳定基线。

这些方向中的离线检查或专项结果不能自动扩张为“长论文全文分析通过真实验收”。真实模型是否完成任务、输出是否完整、内容是否受原文支持以及科研判断是否正确，应分别核验。本轮不继续这些开发或验收活动。

## 后续验证应补充什么

以下均为待审核计划，尚未执行：

1. 明确演示版本和具体任务，逐项列出预期结果与不能声称的范围。
2. 使用原创合成内容与隔离环境，分别验证阅读、定位、术语和翻译记忆路径。
3. 运行任何离线检查前，审查其网络、凭据、文件和数据库副作用。回环 HTTP 不是严格无网络；只有假凭据也不代表不会改变系统状态。
4. 如需真实模型验证，另行明确输入范围、费用边界和验收标准；不得把文档准备授权解释为调用授权。
5. 科研正确性与真实用户价值需要独立人工评估；如要报告量化收益，还需确认任务、比较条件、样本和测量方法。
