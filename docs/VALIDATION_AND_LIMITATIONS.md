# 验证范围与已知限制

本文说明当前作品集展示了哪些内容，以及使用 ResearchOS 时需要注意的主要限制。

## 已展示的功能

本作品集展示的是 ResearchOS v0.1.1，截图和视频记录了该版本实际运行时的几个主要功能界面。

当前素材包括：

- PDF 阅读与科研工作区。
- AI 文献概览。
- 与研究课题关联的阅读建议。
- 选中文本翻译及相关术语展示。

这些材料可以证明相应界面和演示流程曾实际运行，但不代表所有功能均通过了完整的系统测试。

## 已知限制

| 项目 | 当前情况 |
|---|---|
| 分析与摘要输入范围 | 最多传入前 30,000 个字符 |
| 长论文全文分析 | 尚未通过真实验收 |
| 界面响应 | 分析与摘要可能阻塞界面 |
| AI 输出 | 可能存在遗漏或错误，需要对照原文检查 |
| OCR | 不作为当前稳定版已完成能力宣传 |
| 科研笔记与知识关联 | 完整科研笔记系统及部分术语关联能力仍有待完善 |
| 效果数据 | 尚无足够数据支持普遍效率提升或科研正确率等量化结论 |

## 如何理解现有证据

本次截图和视频属于人工演示。它们不替代系统化回归测试、性能测试、兼容性测试或科研正确性评估。

历史离线检查、Mock 测试和版本级人工验收也有各自的适用范围，不能直接推导出真实模型在所有论文上的表现。

后续如需验证长论文处理能力，应单独检查输入完整性、输出是否覆盖预期内容，以及结果是否有原文依据。若要评估效率改善，则需要先确定任务、比较条件和测量方法。

## 使用与数据安全

AI 功能会将提取的文本发送到用户配置的模型服务商，并可能产生费用。使用者应了解相应服务的数据处理规则，并避免发送未经授权的保密材料。

本仓库仅提供产品说明与演示素材，不包含应用源码、EXE、配置文件、数据库或用户日志。
